# お問い合わせ管理基盤SaaS 画面設計書

## 1. 設計方針

### 1.1 基本方針
- **フレームワーク**: Next.js（App Router）
- **UIライブラリ**: Tailwind CSS + shadcn/ui
- **レスポンシブ**: モバイルファースト（ブレークポイント: sm:640px, md:768px, lg:1024px, xl:1280px）
- **アクセシビリティ**: WCAG 2.1 Level AA準拠

### 1.2 共通コンポーネント
- ヘッダー（ロゴ、ナビゲーション、ユーザーメニュー）
- サイドバー（管理画面用、折りたたみ可能）
- ページネーション
- 検索フォーム
- フィルタドロップダウン
- ステータスバッジ
- アラートバナー
- モーダルダイアログ
- トースト通知

## 3. 画面詳細

### 3.1 U-001 問い合わせフォーム

**パス**: `/inquiry/new`
**ロール**: エンドユーザー

| 要素 | 種類 | 必須 | バリデーション |
|------|------|------|----------------|
| カテゴリ | セレクト | ○ | 選択必須 |
| 件名 | テキスト | ○ | 1-100文字 |
| 本文 | テキストエリア | ○ | 1-5000文字 |
| 添付ファイル | ファイル | - | 最大5件、1件10MB、許可形式のみ |
| 送信ボタン | ボタン | - | - |
| 戻るボタン | ボタン | - | return_urlがある場合のみ表示 |

**エラー表示**
- バリデーションエラー: フィールド直下に赤文字で表示
- サーバーエラー: 画面上部にアラートバナー

---

### 3.2 A-002 ダッシュボード

**パス**: `/admin/dashboard`
**ロール**: オペレーター/サービス管理者/テナント管理者

**表示要素**

| セクション | 内容 | 表示条件 |
|-----------|------|----------|
| 対応状況サマリ | 未対応/対応中/回答済み/保留の件数（カード形式） | 常時 |
| アラート | 期限超過/期限間近/長期滞留/未アサインの件数 | 常時 |
| サービス別グラフ | 棒グラフ/円グラフ切り替え | 常時 |
| カテゴリ別グラフ | 棒グラフ/円グラフ切り替え | 常時 |
| 平均初回応答時間 | 数値表示 | 常時 |
| 平均解決時間 | 数値表示 | 常時 |

**インタラクション**
- 数値クリック → 該当フィルタで問い合わせ一覧へ遷移
- 期間選択 → 本日/過去7日/過去30日/カスタム
- リフレッシュボタン → 最新データ取得

**視覚表示優先度**
- 期限超過: `data-alert="overdue"` → 赤色
- 期限間近: `data-alert="warning"` → 黄色
- 未アサイン: `data-alert="unassigned"` → グレー

### 3.3 A-003 問い合わせ一覧

**パス**: `/admin/inquiries`
**ロール**: オペレーター/サービス管理者/テナント管理者

**フィルタ条件**
| フィルタ | 種類 | 選択肢 |
|---------|------|--------|
| サービス | マルチセレクト | 担当サービス一覧 |
| ステータス | マルチセレクト | 未対応/対応中/回答済み/完了/保留 |
| カテゴリ | マルチセレクト | サービスに紐づくカテゴリ |
| 担当者 | セレクト | 未アサイン/担当者名 |
| 期限 | セレクト | 超過/本日/間近/期限内 |
| 期間 | 日付範囲 | 開始日-終了日 |

**一覧表示カラム**
| カラム | 幅 | ソート |
|--------|-----|------|
| ステータスアイコン | 40px | - |
| 問い合わせ番号 | 150px | - |
| サービス | 120px | - |
| カテゴリ | 100px | - |
| 件名 | 可変 | - |
| ユーザー | 120px | - |
| 期限 | 100px | ○ |
| 担当者 | 100px | - |
| 投稿日時 | 150px | ○ |

**視覚表示**
- 期限超過行: 赤背景（`bg-red-50`）
- 期限間近行: 黄背景（`bg-yellow-50`）
- 未アサイン行: グレー背景（`bg-gray-100`）

### 3.4 A-004 問い合わせ詳細

**パス**: `/admin/inquiries/{id}`
**ロール**: オペレーター/サービス管理者/テナント管理者

| 項目 | 操作 |
|------|------|

| ユーザー情報 | 氏名、メールアドレス表示 |
| 期限 | 表示のみ（期限超過/間近は強調） |

**チャットUI**
| 要素 | 配置 | スタイル |
|------|------|---------|
| ユーザー投稿 | 左側 | 白背景、角丸 |
| オペレーター回答 | 右側 | 青背景、角丸 |
| 内部メモ | 右側 | 薄黄背景、🔒アイコン |

**入力エリア**
- テキストエリア（回答/内部メモ切り替え）
- 添付ファイル追加
- 送信ボタン

### 3.5 A-005 オペレーター管理

**パス**: `/admin/settings/users`
**ロール**: サービス管理者/テナント管理者

**一覧表示カラム**
| カラム | 内容 |
|--------|------|
| 名前 | ユーザー名 |

| ロール | オペレーター/サービス管理者/テナント管理者 |
| 担当サービス | サービス名（複数可） |
| ステータス | 有効/招待中/無効 |
| 最終ログイン | 日時 |
| 操作 | 編集/無効化 |

**操作**
- 招待ボタン → ユーザー招待モーダル
- 行クリック → ユーザー編集モーダル

**ユーザー招待モーダル**
| 項目 | 種類 | 必須 |
|------|------|------|
| メールアドレス | テキスト | ○ |

| ロール | セレクト | ○ |
| 担当サービス | マルチセレクト | オペレーター/サービス管理者の場合必須 |
