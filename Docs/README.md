# Claude Code Foundation - ドキュメントガイド

Claude Code Foundationの解説ドキュメント集です。目的に応じて以下のドキュメントをご覧ください。

---

## 📚 ドキュメント一覧

### 1. [クイックリファレンス](./quick-reference.md) ⚡️
**「今すぐ使いたい」「コマンドを確認したい」方向け**

1ページでサッと確認できるチートシートです。

**含まれる内容:**
- ✅ 開発フロー（7つの承認ポイント）
- ✅ スキル呼び出しコマンド一覧
- ✅ 必ず守る5つのルール
- ✅ よく使うコマンド
- ✅ 受入条件（AC）とタスク分解のテンプレート
- ✅ トラブルシューティング

**こんな時に:**
- 「スキルのコマンドは何だっけ？」
- 「開発フローの順番を確認したい」
- 「ACの書き方のテンプレートが欲しい」

**所要時間:** 3分

---

### 2. [実用ガイド](./usage-guide.md) 🛠️
**「具体的な使い方を知りたい」「実践例が見たい」方向け**

シナリオ別の詳しい使い方とベストプラクティスです。

**含まれる内容:**
- ✅ クイックスタート
- ✅ シナリオ別の使い方（5パターン）
  - 新機能開発（フルフロー）
  - 既存コードレビュー
  - コードベース調査
  - エラーハンドリング設計
  - ドキュメント生成
- ✅ ベストプラクティス（6項目）
- ✅ よくある質問（FAQ）
- ✅ トラブルシューティング
- ✅ チートシート

**こんな時に:**
- 「新機能開発の具体的な手順を知りたい」
- 「ベストプラクティスを確認したい」
- 「うまく動かない時の対処法を知りたい」

**所要時間:** 15-20分

---

### 3. [思想と実現内容](./claude-code-foundation-overview.md) 📖
**「背景や思想を理解したい」「体系的に学びたい」方向け**

Claude Code Foundationの設計思想と全体像を詳しく解説します。

**含まれる内容:**
- ✅ 基本思想（スペック駆動開発とは）
- ✅ 3つの設計原則（失敗時挙動先行、非機能先行、運用設計必須）
- ✅ スキルの分類（普遍原則、推奨、壁打ち）
- ✅ ファイル配置の2層構造（ユーザー、プロジェクト）
- ✅ 18の普遍原則（詳細解説）
- ✅ 7つの承認ポイント（Human in the Loop）
- ✅ 14のスキル構成（推奨8個 + 壁打ち6個）
- ✅ セーフティネット（Hooks）
- ✅ 数値目標
- ✅ 実現されること

**こんな時に:**
- 「なぜこの設計思想なのか理解したい」
- 「チームメンバーに説明したい」
- 「普遍原則の背景を知りたい」

**所要時間:** 30-40分

## 🚀 初めての方へ

### ステップ1: まずはクイックリファレンスを見る（3分）
[クイックリファレンス](./quick-reference.md)を開いて、開発フローとスキルコマンドを確認してください。

### ステップ2: 実用ガイドで具体例を見る（15分）
[実用ガイド](./usage-guide.md)の「シナリオ1: 新機能を開発する」を読んで、実際のフローをイメージしてください。

### ステップ3: 小さく始める
簡単な機能で試してみましょう。

```bash
# 最初の一歩
/skill:requirements-definition
```

### ステップ4: 慣れてきたらフルフローで
7つの承認ポイントをすべて通過するフルフローに挑戦してください。

### ステップ5: 思想を理解する（時間がある時に）
[思想と実現内容](./claude-code-foundation-overview.md)を読んで、なぜこの設計なのかを理解してください。

## 🔍 よくある質問

### Q. どのドキュメントから読めばいい？

**A.** 状況によります：
- **今すぐ使いたい** → [クイックリファレンス](./quick-reference.md)
- **具体例が見たい** → [実用ガイド](./usage-guide.md)
- **背景を理解したい** → [思想と実現内容](./claude-code-foundation-overview.md)

### Q. 全部読む必要がある？

**A.** いいえ。まずは[クイックリファレンス](./quick-reference.md)だけ読んで、実際に使いながら必要に応じて他のドキュメントを参照してください。

### Q. チームメンバーに共有したい

**A.** 以下の順番で共有するのがおすすめです：
1. [思想と実現内容](./claude-code-foundation-overview.md) - 設計思想の理解
2. [実用ガイド](./usage-guide.md) - 具体的な使い方
3. [クイックリファレンス](./quick-reference.md) - 日常的に参照

### Q. カスタマイズしたい

**A.** [実用ガイド](./usage-guide.md)の「カスタマイズ」セクションと、[.claude/README.md](../.claude/README.md)の「カスタマイズ」セクションを参照してください。

## 🎓 学習パス

### 初心者向け（所要時間: 30分）
1. [クイックリファレンス](./quick-reference.md) を読む（3分）
2. [実用ガイド](./usage-guide.md) の「クイックスタート」を読む（5分）
3. [実用ガイド](./usage-guide.md) の「シナリオ1」を読む（10分）
4. 実際に小さな機能で試してみる（10分）

### 中級者向け（所要時間: 1時間）
1. [実用ガイド](./usage-guide.md) を全部読む（20分）
2. [思想と実現内容](./claude-code-foundation-overview.md) の「基本思想」を読む（15分）
3. フルフローで新機能を開発してみる（25分）

### 上級者向け（所要時間: 2時間）
1. [思想と実現内容](./claude-code-foundation-overview.md) を全部読む（40分）
2. [実用ガイド](./usage-guide.md) のベストプラクティスを復習（20分）
3. カスタムスキルを作成してみる（1時間）
