# SDDワークフロー 評価指標

## 構造チェック（Pass/Fail）

| 項目 | 基準 | 重要度 |
|------|------|--------|
| 仕様確認の実施 | 不明点が解消されてから実装が開始されている | Critical |
| 実装計画の作成 | タスクがDone条件付きで分解されている | Critical |
| テスト後作成 | テストが実装後に作成されている | Critical |
| チケット紐付け | コミットにチケット番号が含まれている | High |
| テスト改変禁止 | テストを通すための実装改修がない | High |

## 内容チェック（スコアリング）

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| 仕様準拠 | 実装が仕様書に従っている | 30 |
| テスト品質 | 正常系・異常系・境界値がカバーされている | 25 |
| コミット品質 | 変更経緯が記録されている | 25 |
| 追跡可能性 | 要件→設計→実装→テストが追跡可能 | 20 |

## 許容例外

- プロトタイプ・PoC（仕様が流動的な場合）
- 緊急ホットフィックス（後追いでテスト作成）

## 採点基準

- **Pass**: 全Criticalチェック項目がPass かつ スコア80点以上
- **Conditional Pass**: 全Criticalチェック項目がPass かつ スコア60-79点
- **Fail**: CriticalチェックにFailあり または スコア60点未満
