# リリース計画 評価指標

## 構造チェック（Pass/Fail）

| 項目 | 基準 | 重要度 |
|------|------|--------|
| リリース手順の定義 | 具体的なコマンド・操作レベルで記載 | Critical |
| 切り戻し手順の定義 | 具体的なコマンド・操作レベルで記載 | Critical |
| 切り戻し判断基準 | 数値化された判断基準が記載されている | Critical |
| 切り戻し判断者 | 判断者と判断期限が明記されている | High |
| 連絡体制の定義 | 連絡先と連絡タイミングが明記されている | High |

## 内容チェック（スコアリング）

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| 実行可能性 | 手順が経験3年目エンジニアでも実行可能なレベル | 30 |
| 完全性 | 事前準備/リリース/確認/切り戻しの全フェーズが記載 | 25 |
| 安全性 | バックアップ取得、段階的ロールアウトが考慮されている | 25 |
| 復旧性 | 切り戻しが15分以内で実行可能 | 20 |

## 許容例外

- DBマイグレーションがない場合
- メンテナンス不要（無停止デプロイ）の場合

## 採点基準

- **Pass**: 全Criticalチェック項目がPass かつ スコア80点以上
- **Conditional Pass**: 全Criticalチェック項目がPass かつ スコア60-79点
- **Fail**: CriticalチェックにFailあり または スコア60点未満
