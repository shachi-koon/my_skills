# Gitワークフロー 評価指標

## 構造チェック（Pass/Fail）

| 項目 | 基準 | 重要度 |
|------|------|--------|
| ブランチ命名規約 | 規約に従ったブランチ名になっている | Critical |
| コミットメッセージ規約 | チケット番号が含まれている | Critical |
| 変更経緯の記録 | 「何を・なぜ・どう変えたか」が記録されている | High |
| PRの説明 | 変更内容・影響範囲が明記されている | High |

## 内容チェック（スコアリング）

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| 追跡可能性 | コミットからチケットを追跡できる | 30 |
| コミット粒度 | 1コミット=1つの論理的変更 | 25 |
| PR品質 | レビューしやすいサイズと説明 | 25 |
| 履歴の健全性 | 不要なマージコミットがない | 20 |

## ブランチ命名規約

```
feature/{チケット番号}-{機能名}
fix/{チケット番号}-{修正内容}
hotfix/{チケット番号}-{修正内容}
```

## コミットメッセージ規約

```
<type>: <subject> #<ticket-number>

例: feat: ログイン機能追加 #123
例: fix: バリデーションエラー修正 #456
```

## 採点基準

- **Pass**: 全Criticalチェック項目がPass かつ スコア80点以上
- **Conditional Pass**: 全Criticalチェック項目がPass かつ スコア60-79点
- **Fail**: CriticalチェックにFailあり または スコア60点未満
