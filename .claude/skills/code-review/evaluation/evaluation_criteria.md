# コードレビュー 評価指標

## 構造チェック（Pass/Fail）

| 項目 | 基準 | 重要度 |
|------|------|--------|
| セキュリティ観点 | SQLi/XSS/認証認可の観点でレビューされている | Critical |
| エラーハンドリング | 例外処理・リトライ・ログが確認されている | Critical |
| 設計整合性 | 設計書との整合性が確認されている | High |
| テスト観点 | テストカバレッジ・品質が確認されている | High |
| Good Points | 良い点も言及されている | Medium |

## 内容チェック（スコアリング）

| 観点 | 評価基準 | 配点 |
|------|----------|------|
| 指摘の具体性 | 行番号・コード例・改善案が具体的 | 30 |
| 重要度分類 | Critical/Warning/Infoに適切に分類されている | 25 |
| 観点の網羅性 | セキュリティ/性能/保守性/テストが網羅されている | 25 |
| 建設性 | 指摘だけでなく改善案が提示されている | 20 |

## 許容例外

- 設計書がない場合（コードから意図を推測）
- 緊急ホットフィックス（最低限のセキュリティチェックのみ）

## 採点基準

- **Pass**: 全Criticalチェック項目がPass かつ スコア80点以上
- **Conditional Pass**: 全Criticalチェック項目がPass かつ スコア60-79点
- **Fail**: CriticalチェックにFailあり または スコア60点未満
